# Xerxes repository guidance

Start with `../XERXES.md` and `../WORKSPACE.md` from the repository root's `.xerxes` directory.

- `agents/`: specialist instruction documents.
- `skills/`: workflow skills and their index.
- `commands/`: reusable task prompts.
- `ops/`: operational runbooks.
- `projects/`: preserved project notes.
- `repo-map.yaml`: repository map.

This migration renames the repository guidance and updates its paths. It does not register tools or agents, translate tool allowlists, or guarantee that a particular Xerxes installation automatically discovers every document. Use the tools and agent types actually available in the running session.
